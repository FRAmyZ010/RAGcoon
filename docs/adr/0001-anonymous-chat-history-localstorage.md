# Anonymous chat history: localStorage first, server workspaces transitional

General Users must ask the RAG without authentication. Advisor feedback pushed durable personal chat history toward the browser (localStorage) rather than a server-side identity-bound log. We therefore treat localStorage as the intended source of what the user sees as their Workspace history, and send multi-turn context from the client with each request. Existing `/chat/workspaces*` persistence remains temporarily in parallel so Sprint 2 can ship Admin auth and documents without a hard cutover; a later change should remove the dual path so the server is not a second source of truth for anonymous transcripts. FAQ and usage analytics are separate concerns and must not reintroduce full personal Q&A logs without an explicit new decision.
